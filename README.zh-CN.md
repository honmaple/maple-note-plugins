# 红枫笔记插件

[English](README.md) | 简体中文

为红枫笔记提供远程笔记服务接入。插件在红枫笔记服务端运行，用于浏览、创建、更新、删除远程笔记，以及上传和预览附件。

## 安装

在红枫笔记的远程插件管理中添加本仓库的 `index.json` 直链作为插件源，选择需要的插件安装，再创建使用该插件的远程服务并填写配置。

也可以使用下表中的 JS 文件直链单独安装。使用能够直接返回 JSON 或 JavaScript 内容的地址，例如仓库文件的 Raw 链接；不要使用仓库文件浏览页面的链接。

| 插件 | 分发文件 | 接入说明 |
| --- | --- | --- |
| Memos | [usememos/usememos.js](usememos/usememos.js) | 面向 Memos v0.24.2 |
| Memos v0.31.0 | [usememos/usememos_v031.js](usememos/usememos_v031.js) | 面向 Memos v0.31.0，支持 SPACE 可见性 |
| Blinko | [blinko/blinko.js](blinko/blinko.js) | 支持 Token 或账号密码登录 |
| 思源笔记 | [siyuan/siyuan.js](siyuan/siyuan.js) | 一条记录对应指定笔记本中的一篇文档 |

插件索引为 [index.json](index.json)，脚本路径相对于索引所在目录。将本仓库作为静态文件发布时，应保留目录结构。远程服务的接入点必须能从红枫笔记服务端访问。

## 服务说明

| 服务 | 插件 | 适用版本 | 必填配置 | 认证 | 核心能力 |
| --- | --- | --- | --- | --- | --- |
| Memos | `usememos` | v0.24.2 | `endpoint` | Token | 笔记读写、附件上传与复用 |
| Memos | `usememos_v031` | v0.31.0 | `endpoint` | Token | 笔记读写、附件上传与复用、SPACE 可见性 |
| Blinko | `blinko` | — | `endpoint` | Token 或账号密码 | 笔记读写、附件上传与复用 |
| 思源笔记 | `siyuan` | — | `endpoint`、`notebook` | API Token | 文档读写、Markdown 编辑、资源上传与预览 |

### Memos

两个版本使用不同插件，无需版本参数。Token 可留空以浏览实例允许公开访问的笔记；v0.31.0 需要在 Memos 中允许公共访问。创建、更新和删除需要 Token。删除执行归档，不永久删除。

支持本地上传和外链附件。本地上传需要支持 JSON 附件上传的红枫笔记服务端；更新完整替换附件列表，空列表解除全部关联。创建 SPACE 可见性的笔记时，需要在笔记表单填写空间 ID（`spaces/ID`）。

### Blinko

Token 优先于账号密码；使用账号密码时，`username/password` 必须同时填写。不提供认证信息时，仅可浏览远端允许公开访问的笔记。删除将笔记移入回收站。

支持本地上传、外链导入和已有附件复用。当前 upsert 接口不解除已有附件关联，移除会返回错误，需要在 Blinko 中处理。

### 思源笔记

一条记录对应指定笔记本中的一篇文档。内核无需认证时，Token 可留空。列表依赖 SQL API，不适用于发布模式。

更新会替换文档正文，可能重新生成子块 ID，思源特有块结构不能保证无损往返。移除附件只删除正文引用，不删除共享资源。原生文档删除可能连带删除子文档，建议使用单独的笔记本。

## 更新与反馈

通过红枫笔记的远程插件管理检查并安装插件更新。插件版本可在 JS 文件头部查看；插件版本与远程服务版本分别维护。

反馈问题时，请提供插件名称及版本、红枫笔记版本、远程服务版本、操作步骤和错误信息。Blinko 与思源目前已通过模拟 API 测试，尚未完成真实实例验证。
